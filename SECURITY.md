# Politique de sécurité

La sécurité et la vie privée des utilisateurs passent avant tout. Nous remercions toute personne qui nous aide à les protéger.

## Signaler une faille

- N'ouvrez pas de ticket public pour une faille.
- Utilisez le signalement privé de GitHub : onglet « Security » du dépôt, puis « Report a vulnerability ».
- Décrivez le problème, les étapes pour le reproduire et, si possible, l'impact.

## Nos engagements

- Accusé de réception sous 72 heures.
- Information régulière sur l'avancement de la correction.
- Publication d'un correctif et, avec votre accord, remerciement public une fois la faille corrigée.
- Aucune poursuite contre une recherche de bonne foi qui respecte la vie privée des utilisateurs et ne dégrade pas le service.

## Versions couvertes

Le projet est en phase 0 (fondations). Seule la branche `main` est maintenue.
