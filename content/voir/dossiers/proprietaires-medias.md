::: en-bref
- Une poignée de groupes possède la plupart des médias nationaux.
- Leurs propriétaires ont souvent d'autres activités (industrie, banque, télécommunications) qui dépendent de décisions publiques.
- PPF analyse les lignes éditoriales selon une méthode publique et chiffrée, jamais par simple appréciation.
:::

**[EXEMPLE] Brouillon de démonstration : les groupes cités sont fictifs.**

## Les groupes (exemple)

- **Groupe Exemple Médias** : un quotidien national, deux radios, une chaîne d'information ; son actionnaire principal est aussi présent dans la construction.
- **Modèle Presse** : une vingtaine de titres régionaux ; il appartient à une banque.

## La méthode

Pour chaque média : temps de parole par sujet, choix des sujets, invités. Les relevés sont publiés avec leurs données, pour que chacun puisse les refaire.
