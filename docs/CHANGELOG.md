### Corrigé
- Android, version de test envoyée sur les téléphones (D-031) : c'était la version de développement, débogable (lisible par câble) et toujours numérotée 1. Nouvelle version d'essai `android-preview.apk`, non débogable, même identifiant et même clé de test (elle s'installe par-dessus l'ancienne), numéro de version croissant à chaque commit ; l'intégration continue vérifie qu'elle n'est pas débogable et qu'elle porte le certificat de test ; guide d'installation pour les Samsung (Bloqueur automatique, Google Play Protect) dans `docs/guides/installer-version-test-android.md`.
- Application de bureau empaquetée : le moteur Java allégé n'embarquait pas le module `java.sql` nécessaire à la base locale ; l'application ne démarrait plus. Modules ajoutés d'après `gradlew :desktop:suggestRuntimeModules`.
- APK Android : les ressources Compose (textes de l'interface, fiches intégrées) n'étaient pas empaquetées, parce que le nouveau plugin Android des bibliothèques multiplateformes désactive les ressources par défaut (`androidResources { enable = true }` manquait). Les APK précédents ne pouvaient pas afficher leur premier écran. Vérification ajoutée : présence des ressources dans l'APK.
- Dépendances : `secp256k1-kmp` 0.24.0 et `bitcoin-kmp` 0.32.0 (ACINQ, Apache 2.0) ; `kotlinx-coroutines-core` et `kotlinx-coroutines-test` 1.11.0 ; SQLDelight 2.4.1 ; Ktor client 3.6.1 ; HikariCP 7.1.0 ; Flyway 13.12.1 ; pilote PostgreSQL 42.7.14 ; embedded-postgres 2.2.2 avec PostgreSQL 17.11 (tests).
